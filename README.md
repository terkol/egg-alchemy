# Egg Alchemy

This mod is extremely simple, programmatically and artistically. It only adds one item: the **Transmuted Egg**. The Transmuted Egg can be crafted from an egg using blaze powder, gunpowder and glowstone dust. 

When held and right-click is pressed, the Transmuted Egg will disappear and a random item generated from the game's registry will spawn at the player's feet. There are no safeguards preventing the player from gaining otherwise unobtainable items with this mod. 

## Versions
- Minecraft version: **1.12.2**
- Loader: **Forge**
- No dependencies

## Install
1. Install the recommended forge loader version for Minecraft **1.12.2**.
2. Download `egg-alchemy-1.0-1.12.2.jar` from the root folder of Untiered Items.
3. Put the `.jar` into your `mods` folder.
4. Launch game. 

## Development

### Build
```bash
./gradlew build
```
### Run client
```
./gradlew runClient
```
